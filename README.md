# Twenty Eight Caffee — The room

An artistic Romanian-first café concept in Next.js, Tailwind and GSAP. Uses supplied reference photography, custom floral SVG ornaments inspired by the exterior, layered scroll scenes and an accessible shadcn/Radix photo gallery.

## Local preview

```powershell
npm install
npm run dev
```

Open [the local preview](http://localhost:3028/). This project uses port 3028 so it can run alongside other website projects. `npm run build` creates a static export in `out/`; `npm run typecheck` checks TypeScript.

## Editing

- `src/data/cafe.ts`: one content source for address, hours, contact links and drinks categories.
- `src/components/CafeExperience.tsx`: composition, gallery and motion.
- `src/components/Motif.tsx`: original vector floral medallions.
- `src/app/globals.css`: design and responsive behaviour.
- `design.md`: chosen direction and full interaction map.
- `CONTENT-NOTES.md` and `public/images/ASSETS.md`: production content/asset approvals still needed.

This is an internal concept preview. Search indexing is disabled. No current prices, booking system, food service, promotions or legal entity details have been invented. The directions link, phone, email and social links use the supplied brief. Supplied Instagram screenshots are temporary reference assets pending clean approved originals and rights confirmation.
